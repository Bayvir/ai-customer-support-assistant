# AI Customer Support Assistant

An AI-powered customer support assistant designed to help businesses categorize customer issues and generate professional, helpful responses.

## Project Overview

This project demonstrates how AI can be used to improve customer support workflows.

The assistant takes a customer message and helps:

- Identify the type of customer issue
- Determine the urgency of the request
- Generate a professional customer-service response
- Provide a recommended next action

## Example

### Customer Message

> "I've been trying to reset my password but I haven't received the reset email."

### AI Analysis

**Category:** Account / Login  
**Priority:** Medium  
**Issue:** Password reset email not received

### Suggested Response

"Hi, thank you for reaching out. I'm sorry you're having trouble resetting your password. Please check your spam or junk folder to see if the reset email was filtered there. If you still don't receive it, please let us know and we can help you with the next steps."

### Recommended Action

Check the customer's account and resend the password reset email if necessary.
